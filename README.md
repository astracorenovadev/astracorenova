# AstraCoreNova

Незалежний бізнес-сайт: https://astracorenova.com/. Поточні продажні доробки — у `sales-v2`. Публікація у `main` — після локального перегляду власником.

Локальний перегляд: `python -m http.server 4180 --bind 127.0.0.1` у корені репозиторію.

Публічний сайт містить тільки статичні сторінки та ресурси. Рев’ю, скриншоти, звіти та інструменти збирання збережені локально поза репозиторієм: `C:\ACN-бізнес\acn\docs\site-review\` і `C:\ACN-бізнес\tooling\sales\`. Генератор: `python ..\tooling\sales\build-home.py`.

Публічна конфігурація — тільки `assets/js/sales-config.js`: `WEB3FORMS_KEY`, `TELEGRAM_URL`, `CF_BEACON_TOKEN`. Поки значень немає, анкета не імітує успішного надсилання, показує запасний email; Telegram не веде на вигадану адресу, аналітика не завантажується. Текст `privacy.html` — явна заглушка, очікує погодженого тексту Claude.

Web3Forms: після отримання ключа власник має увімкнути обов’язкову hCaptcha у налаштуваннях форми. Серверну перевірку виконує Web3Forms; секрет hCaptcha у сайт не додається. Див. [офіційну інтеграцію](https://docs.web3forms.com/getting-started/customizations/spam-protection/hcaptcha).

Cloudflare Web Analytics підключається тільки після заповнення токена. Власних аналітичних cookie сайт не створює. Див. [офіційне підключення](https://developers.cloudflare.com/web-analytics/get-started/).

Сцена має окремий мобільний бюджет: DPR ≤ 1, ліміт 30 fps, одна статуя одночасно, без bloom і динамічних тіней. Для сучасних телефонів обмежена кількість логічних ядер у браузері не є автоматичною причиною вимикати WebGL2. Слабкі пристрої, reduced motion та saveData зберігають постери.
